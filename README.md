# JPTV25-EduSchedule
"EduSchedule" on Telegrami bot kodutööde haldamiseks ja jälgimiseks.
Простой и удобный Telegram-бот для учёта, добавления и остлеживания домашних заданий.


# 🛠 Tehnoloogiad (Технологии)
"Python 3.10+"- основной язык программирования
"aiogram 3.x" - библиотека для создания Telegram-бота.
"SQLite3" - база данных для хранения списка ДЗ.


# 🚀 Funktsioonid (Функционал)
"Kodutööde lisamine" - добавление новых домашних заданий по предметам.
"Ülesannete nimekiri" - просмотр списка всех актуальных заданий.
"Staatused" - отметка выполненых заданий.
